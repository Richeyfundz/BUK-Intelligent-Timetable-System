About System

Information about BUK ITMS
BUK Intelligent Timetable Management System

System Overview

BUK Intelligent Timetable Management System (BUK ITMS) is a web-based academic scheduling system developed to automate timetable creation and management within Bayero University Kano.

The system helps administrators manage faculties, departments, courses, lecturers, students and venues while reducing timetable conflicts.

Main Features

  • Faculty and Department Management
  • Course Management
  • Lecturer Management
  • Student Management
  • Venue Management
  • AI Timetable Generation
  • Examination Timetable Generation
  • Report Generation
  • Data Backup System

Scheduling Algorithm

The system uses a combination of:

  • Constraint Satisfaction Algorithm
  • Greedy Scheduling Algorithm

These algorithms help assign courses, venues and time slots while avoiding conflicts.

Technology Used

  • HTML5
  • CSS3
  • JavaScript
  • Bootstrap 5
  • Local Storage Database
