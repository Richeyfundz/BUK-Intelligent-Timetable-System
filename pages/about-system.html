AI-Assisted Academic Scheduling and Conflict Detection

System Overview

The BUK Intelligent Timetable Management System (BUK ITMS) is a web-based academic scheduling application designed to support timetable preparation and management at Bayero University Kano.

The system provides a centralized platform for managing academic information and generating lecture timetables. Its scheduling process considers course assignments, lecturers, available venues, academic levels, time slots, and scheduling constraints to help reduce timetable clashes.

The system is intended to support academic administrators in organizing scheduling information more efficiently and reviewing generated timetables before saving them.

Core System Modules

Academic Management

Organizes faculties, departments, courses, lecturers, students, and teaching venues.

AI-Assisted Timetabling

Allocates eligible courses to suitable days, time slots, lecturers, and available venues using scheduling rules.

Conflict Detection

Checks scheduling assignments for lecturer, venue, and academic-level time conflicts.

Examination Scheduling

Provides an examination timetable module for organizing and managing examination schedules.

Reports

Presents timetable information and academic record summaries to support administrative review.

System Administration

Provides access to system settings and user-management functions according to the available implementation.

Scheduling Approach

The timetable generator uses a constraint-based scheduling approach with greedy allocation techniques to assign courses to available scheduling slots.

Important scheduling constraints
  • Assign courses to their eligible academic levels and semester.
  • Use the actual lecturer-course assignments recorded in the database.
  • Avoid overlapping assignments for the same lecturer.
  • Avoid assigning the same venue to simultaneous classes.
  • Prevent overlapping classes for the same academic-level group.
  • Respect the configured lecture days and time slots.
  • Keep the Friday Jumu’ah break from 1:00 PM to 2:30 PM free.
Generated timetables should be reviewed by the administrator before they are saved or published.

Project Scope

The project focuses on supporting academic timetable administration within Bayero University Kano, with particular attention to the Faculty of Computing and its academic scheduling requirements.

The system is designed to improve scheduling organization, reduce avoidable clashes, and make timetable information easier to manage and review.
